# ephemera

a home for various trinkets, experiments, & disjecta membra. lasciate ogne speranza, voi ch'intrate.

## installation

assuming you've already added vivimart as a marketplace:

```
/plugin install ephemera@vivimart
```

## what's inside

- `/ephemera:headpat` — pat Claude on the head for doing a good job. a warm randomized response & a quiet morale boost for the rest of the session.
