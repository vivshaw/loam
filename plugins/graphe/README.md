# graphe

writing tools.

## what's inside

**skills:**

- `graphe:polishing-a-paragraph`: improves a passage of prose using Francis Christensen's sentence-construction approach
- `graphe:writing-for-a-technical-audience`: prose craft for docs, commit messages, and explanations
