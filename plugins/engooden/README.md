# engooden

pulled from [Mike Caulfield's post here](https://mikecaulfield.substack.com/p/a-300-word-prompt-that-makes-llm), this is a skill that applies Francis Christensen's approach to rhetoric to de-LLMify text, improving its clarity and interest. i'd advise applying it largely at the paragraph level, as Claude might not do so well at working through a whole text in one shot with this approach.

## installation

assuming you've already added vivimart as a marketplace:

```
/plugin install engooden@vivimart
```

## usage

one command is available:

- `/enooden:engooden` — improve a passage of text, using Francis Christensen's sentence-construction approach
