# sophia

viv shaw's house style: coding standards & language-specific patterns.

## installation

assuming you've already added nous as a marketplace:

```
/plugin install sophia@nous
```

## what's inside

**craft standards:**

- `coding-effectively` — overarching code quality principles (called by `morphe` agents to drive reviews and fixes)
- `defense-in-depth` — validation at multiple layers
- `writing-good-tests` — test quality and what to test (vs. what not to)
- `property-based-testing` — generative testing patterns
- `howto-functional-vs-imperative` — when and how to apply each
- `writing-for-a-technical-audience` — prose craft for docs, commit messages, and explanations

**language-specific:**

- `howto-code-in-rust`
- `howto-code-in-typescript` (with `type-fest.md` and `typebox.md` references)
- `howto-develop-with-postgres` (with `typescript-drizzle.md` reference)
- `programming-in-react` (with `react-testing.md` and `useEffect-deep-dive.md` references)
