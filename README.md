# welcome to vivimart

the one-stop shop for vivshaw's Claude sundries

## setup

add vivimart as a marketplace in Claude Code:

```
/plugin marketplace add vivshaw/vivimart
```

then browse and install plugins:

```
/plugin install techne@vivimart
```

to update all plugins from vivimart later:

```
/plugin marketplace update vivimart
```

## currently in stock

- [techne](plugins/techne/README.md), an opinionated research -> plan -> implement -> review workflow that is the core of this repo
 - [ephemera](plugins/ephemera/README.md), trinkets, experiments, disjecta membra
 - [graphe](plugins/graphe/README.md), writing tools. currently: engooden.
